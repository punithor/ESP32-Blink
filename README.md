# ⚡ Smart EV Charging Station Optimizer using IoT and Edge AI

## 📌 Project Overview

The Smart EV Charging Station Optimizer is an IoT-based project developed as part of the Emertxe Live IoT Internship 2026. The project focuses on developing an intelligent EV charging management system using ESP32, IoT, MQTT communication, ThingsBoard cloud integration, and Edge AI concepts.

The system monitors charging parameters, collects sensor data, communicates with the cloud, and makes intelligent charging decisions to optimize the charging process.

## 🎯 Objectives

- Develop an IoT-based smart EV charging monitoring system.
- Monitor voltage, current, power, and energy consumption.
- Implement Wi-Fi connectivity using ESP32.
- Enable MQTT-based communication.
- Integrate ThingsBoard for real-time cloud monitoring.
- Apply Edge AI concepts for intelligent charging decisions.
- Improve charging management through automated control.

## ⚙️ Project Features

1. **Real-Time Monitoring:** Monitors voltage, current, power, and energy consumption.

2. **Temperature Monitoring:** Uses the DHT22 sensor to monitor environmental conditions.

3. **IoT Connectivity:** Uses ESP32 Wi-Fi connectivity for cloud communication.

4. **MQTT Communication:** Transfers device telemetry to the ThingsBoard platform.

5. **Cloud Dashboard:** Displays charging parameters and system status.

6. **Intelligent Charging Decisions:** Uses Edge AI concepts to support charging decisions.

7. **Relay Control:** Supports turning the relay ON and OFF through dashboard controls.

8. **Charging Management:** Displays charging status, charging duration, and arrival probability.

## 📊 ThingsBoard Dashboard

The ThingsBoard dashboard provides real-time visualization of the charging system.

Dashboard parameters include:

- Voltage
- Current
- Power
- Charging Status
- Charging Decision
- Charging Duration
- Energy Consumption
- Arrival Probability
- Relay ON/OFF Control
- Throttle Control

## 🔄 Working Process

1. ESP32 collects input data from the connected sensors and components.
2. The system processes the collected information.
3. Wi-Fi provides internet connectivity.
4. MQTT transfers telemetry data to ThingsBoard Cloud.
5. ThingsBoard displays the received information through a dashboard.
6. Charging decisions are generated using the implemented optimization and Edge AI concepts.
7. Relay control allows charging operations to be managed through the dashboard.

## 🖥️ Simulation

The hardware circuit is designed and tested using the Wokwi Simulator.

The simulation includes ESP32, sensors, relay, LEDs, buttons, and other connected components.
